# TDS_GUi
## 準備
1. ドライブ直下に`Apps`というフォルダを作成する。<br>
2. ダウンロードしたファイル`TDS_GUi`をそのフォルダに格納する。<br>
3. `CreateShortcut.vbs`をダブルクリックする。<br>
4. RStudioにて、`app.R`, `differences.R`, `global.R`, `trajectory.R`をそれぞれ開く。<br>
5. 各ファイルに不足のライブラリーをインストールするかというウィンドウが出るので、インストールする。<br>
6. デスクトップに作成されたTDS_GUiのショートカットをダブルクリックして、しばらく待つとウィンドウが開くと成功です。<br>

## 使い方 
デモデータが付いているので、データの型はそちらを参照してください。
